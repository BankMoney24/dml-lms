## Security controls in place

Parameterised SQL everywhere · uploads checked by content, stored outside the web root, served only after an access check (text as text/plain under a sandbox CSP), per-school quota, optional ClamAV with fail-closed scanning · two-step sign-in for owners/admins · hashed single-use account links · DB-backed rate limits on reset requests · contextual output escaping · CSRF on all state changes · `__Host-` secure session cookie, rotation on login/logout · login throttling · strict CSP with no inline code · `X-Frame-Options: DENY`, `nosniff`, referrer and permissions policies, HSTS on HTTPS · `Cache-Control: no-store` on pages · user-facing errors carry a request id, never internals · IPs in audit stored as keyed hashes · composite foreign keys against cross-tenant writes · secrets only in `shared/.env` · forced-command deploy key · actions pinned to SHAs.

## Content

`courses/linux-server-administration`: an advanced, complete course (8 modules, 21 readings, 7 module quizzes and a 20-question final exam with explanations, 3 teacher-reviewed assignments including a capstone, about 40 hours) covering AlmaLinux and Ubuntu. Import with `bin/console course:import <tenant> linux-server-administration --publish`.

## Interface

Shared components rendered by `ViewHelpers` (labelled fields with inline errors, error summary linking to fields, badges, empty states, breadcrumbs), role-aware navigation with the current section marked, the same page-header pattern on every screen, two-step confirmation for destructive actions, and course tabs (Outline / Learner progress) in the teaching workspace. Course cards share one layout (module trace, kind of course, title, summary, a footer with facts and progress or price); one start box on the course page for every state; lesson pager cards; sign-in page with the school beside the form; staff home split into a to-do list, their classes and their courses; find-as-you-type on People and learner lists; add-a-lesson shows only the fields the chosen type uses; tables that stack into records on phones. DML Technologies brand (ADR 0014): logo blue and black on light surfaces, navy with red on dark panels, square pixels for progress, Learn / Build / Grow, footer credit to TridaxLabs. Search: descriptions, Open Graph, canonical addresses and schema.org Course and EducationalOrganization data on public pages, noindex elsewhere, per-school robots.txt and sitemap.xml.
