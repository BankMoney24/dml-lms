## Cisco Packet Tracer

**Cisco Packet Tracer** is a free network simulator from Cisco Networking Academy, widely used in networking courses and Cisco certification study. It models real Cisco routers and switches in much more detail than the network builder here: VLANs, DHCP, wireless, dynamic routing protocols and more.

## Getting it

1. Create a free account at [netacad.com](https://www.netacad.com) (Cisco Networking Academy).
2. Enrol in the free course **Getting Started with Cisco Packet Tracer**, which gives access to the download.
3. Install it on Windows, macOS or Ubuntu. It does not run on Chromebooks.

> **Note:** The installer is large (several hundred megabytes). Download it on Wi-Fi.

## Files

- A **.pkt** file is a saved network.
- A **.pka** file is an **activity**: a network with instructions and a built-in checker that shows your percentage as you work.

Your teacher can attach `.pkt` and `.pka` files to lessons here; download them and open them in Packet Tracer. You can also hand in your own `.pkt` file for an assignment.

## How it relates to the labs here

The network builder labs in this course work in any browser, including on a phone, and are marked automatically. Packet Tracer goes further and is worth learning if you plan a career in networking. Everything you practised here (cabling, addressing, `no shutdown`, static routes, ping and tracert) works the same way there.
